# Long-Term Agentic Memory with LangGraph

## O que aprendi

- memória de curto prazo e memória persistente;
- memória semântica para fatos;
- memória episódica para experiências;
- recuperação de informações relevantes;
- necessidade de critérios para escrita e atualização da memória.

## Relação com CTI

Um agente pode preservar investigações anteriores, preferências do analista e padrões recorrentes. A memória não deve transformar suspeitas em fatos sem validação.

## Experimento

`experiments/02-memoria-longo-prazo/main.py`

Salva fatos e episódios em JSON e permite recuperação simples.

## Principal conclusão

**Memória útil não é guardar tudo; é preservar o que terá valor futuro e registrar sua origem.**
