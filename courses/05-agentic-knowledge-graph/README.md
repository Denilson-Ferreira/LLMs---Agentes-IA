# Agentic Knowledge Graph Construction

## O que aprendi

- entidades são nós;
- relações são arestas;
- grafos representam conexões entre ameaças;
- agentes podem extrair relações de textos e atualizar o grafo;
- conexões sugerem hipóteses, mas não provam atribuição sozinhas.

## Relação com CTI

O grafo pode relacionar grupos, malwares, CVEs, IOCs, técnicas e organizações. Isso ajuda a encontrar padrões entre incidentes.

## Experimento

`experiments/05-grafo-conhecimento/main.py`

Cria um grafo simples e exporta um arquivo DOT.

## Principal conclusão

**Uma lista mostra elementos; um grafo mostra como eles estão conectados.**
