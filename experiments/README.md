# Experimentos

Todos os experimentos são didáticos e usam apenas a biblioteca padrão do Python.

## Executar todos

```bash
python run_all.py
```

## Importante

- O relatório de entrada é fictício.
- Os endereços usados são reservados para documentação.
- Nenhum experimento realiza varredura, bloqueio, consulta externa ou ação em sistemas reais.
- O objetivo é demonstrar arquitetura e raciocínio, não operar como ferramenta de segurança.
